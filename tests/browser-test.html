7. Known Browser Issues & Workarounds

Internet Explorer 11 (Legacy Support)

Status: Not supported (discontinued by Microsoft)

Fallbacks: Graceful degradation with basic CSS

Safari-Specific Issues

  • CSS Grid: Check for proper gap support (Safari 12+)
  • Flexbox: Verify gap property fallbacks (Safari 14.1+)
  • Smooth scrolling: Test scroll-behavior CSS property
  • Font rendering: Verify -webkit-font-smoothing

Mobile Browser Considerations

  • iOS Safari: 100vh viewport issues with address bar
  • Android Chrome: Touch event handling
  • Mobile Firefox: Font size adjustments
  • Samsung Internet: CSS custom properties support
